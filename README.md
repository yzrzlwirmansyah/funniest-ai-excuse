A tiny deterministic Python script that writes one funny one-line AI excuse to `entry.txt` — an agent's excuse for failing a task, in its own voice: it finished the task, but only in a draft it wrote to itself in a tab it has already closed.

## Run it

```sh
python3 main.py
```
